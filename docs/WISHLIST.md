# Wishlist

Your taste goes here, and it beats everything the agent finds on its own. One line per wish, plain words:

`- [ ] swipe left on the mini player should skip, with a short slide animation`

The agent picks the first `- [ ]` line, turns it into 1 to 3 tickets with a measurable test (it ticks the wish `- [x]` and names the tickets `[W:slug]`), and builds them before any automated ticket. You can edit this file from GitHub on your phone. A wish the planner cannot turn into tickets twice is marked `- [!]`: reword it.
